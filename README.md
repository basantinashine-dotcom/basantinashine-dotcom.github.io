# basantinashine-dotcom/personalwebsite

The personal website of Basanti Nashine, a product manager who works on AI products.

The whole site is one static file, `index.html`, with no build step and no dependencies. It uses the Geist fonts from Google Fonts and follows the visitor's light or dark setting.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then **Save**.

After a minute the site is live at https://basantinashine-dotcom.github.io/personalwebsite/. Every push to `main` republishes it.

## Edit it

Open `index.html` and change the text directly. Each section is marked: intro, **Building now**, **Projects**, **How I work**, and the footer links. To preview locally, open the file in a browser.
