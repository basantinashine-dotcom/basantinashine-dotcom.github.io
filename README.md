# basantinashine-dotcom/personalwebsite

The personal website of Basanti Nashine, Head of Product at Orcana.AI and former Principal PM-T at Amazon.

The site is one static file, `index.html`, plus the intro photo, with no build step and no dependencies. It uses the Geist fonts from Google Fonts and follows the visitor's light or dark setting.

The photo comes in three files: `photo-600.webp` and `photo-1200.webp` for modern browsers, and `photo-1200.jpg` as the fallback and the social preview image. To change it, replace all three with a 3:2 crop at the same sizes.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then **Save**.

After a minute the site is live at https://basantinashine-dotcom.github.io/personalwebsite/. Every push to `main` republishes it.

## Edit it

Open `index.html` and change the text directly. The sections run in this order: intro with photo, **Impact**, **Experience**, **Side projects** (Hey Mama and the project list), **How I work**, and the footer links. To preview locally, open the file in a browser.
